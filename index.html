A lightweight custom shell implemented in C that mimics core Linux terminal behavior — command execution, built-in commands, process control and signal handling.

Every time you type a command in a Linux terminal, a shell parses it, forks a child process, and executes it. This project builds that entire pipeline from scratch — using fork(), execvp(), waitpid() and signal handling in C.

// HOW IT WORKS

The Shell Pipeline

Every command you type in a shell goes through the same pipeline — read input, parse it into tokens, check if it is a built-in or external command, then execute it using the correct system call.

01
Read & Parse Input
The shell reads a line of input using fgets(). It then tokenizes the input by splitting on spaces and special characters to produce an argv-style array of arguments.
strtok(input, " \t\n")
02
Fork Child Process
For external commands, the shell calls fork() to create a child process. The child calls execvp() to replace itself with the requested program. The parent waits using waitpid().
pid = fork() → execvp(args[0], args)
03
Handle Signals
SIGINT (Ctrl+C) is caught to prevent the shell from terminating. SIGCHLD is handled to clean up zombie processes when child processes finish execution.
signal(SIGINT, handler)
// EXECUTION FLOW

External vs Built-in Commands

When a command is entered, the shell first checks if it is a built-in. If yes it handles it directly. If no, it forks a child process and uses execvp() to run the external program.

EXTERNAL COMMAND — e.g. ls, wc, sleep
1
Read input and tokenize into argv array
strtok(line, " \t\n")
2
Check — not a built-in command
strcmp(args[0], "cd") != 0 ...
3
Fork a child process
pid = fork()
4
Child executes the command
execvp(args[0], args)
5
Parent waits for child to finish
waitpid(pid, &status, 0)
SHELL CORE
BUILT-IN COMMAND — e.g. cd, pwd, exit
1
Read input and tokenize into argv array
strtok(line, " \t\n")
2
Match command against built-in list
strcmp(args[0], "cd") == 0
3
Execute built-in directly in shell process
chdir(args[1]) — no fork needed
4
Update shell state if needed
getcwd(cwd, sizeof(cwd))
5
Return to prompt — no child process
continue — back to read loop
// BUILT-IN COMMANDS

Shell Built-ins

Built-in commands run directly inside the shell process — no fork, no exec. They need direct access to the shell's internal state like the current directory or environment variables.

cd
Changes the current working directory. Uses chdir() system call. Updates the shell's internal cwd state on success.
cd <path> | cd ..
pwd
Prints the current working directory path. Uses getcwd() to retrieve the absolute path from the OS.
pwd
echo
Prints arguments to standard output. Handles multiple arguments separated by spaces with a newline at the end.
echo <message>
exit
Cleanly terminates the shell process. Frees allocated memory, closes open file descriptors and exits with the given status code.
exit | exit <code>
help
Lists all available built-in commands with their usage. Gives the user a quick reference without leaving the shell.
help
External
Any command not in the built-in list — ls, wc, cat, grep, sleep — is executed via fork() + execvp() as a child process.
ls | wc | grep | cat ...

What It Does

⚡
External Command Execution
Executes any Linux command using fork() and execvp(). The child process replaces itself with the requested program. Parent waits using waitpid().
🔧
Built-in Commands
Implements cd, pwd, echo, exit and help as internal shell commands. These run directly in the shell process without forking a child.
🔀
Input Parsing & Tokenization
Splits raw input into an argv-style array using strtok(). Handles multiple arguments, spaces and special characters cleanly.
🛡️
Signal Handling
SIGINT (Ctrl+C) is caught to prevent accidental shell termination. SIGCHLD handles zombie process cleanup automatically when children exit.
🔄
Child Process Management
Tracks child process IDs using waitpid(). Prevents zombie processes. Handles both foreground and background process states correctly.
🧱
Modular Architecture
Separate modules for input reading, parsing, built-in execution, external execution and signal handling. Clean, readable and extensible.

Built With

LANGUAGE
C Programming
Pure C with no external libraries. Every shell feature — parsing, forking, executing, signal handling — built from scratch using system calls.
PROCESS
fork / exec / wait
fork() creates child processes. execvp() replaces child with the requested program. waitpid() synchronizes parent and child execution.
SIGNALS
Signal Handling
SIGINT caught to protect the shell from Ctrl+C termination. SIGCHLD used for automatic zombie process cleanup using signal() and sigaction().
PARSING
Input Tokenization
strtok() splits input into tokens. argv-style array built for execvp(). Handles edge cases — empty input, extra spaces, newline characters.
POSIX
Linux System Calls
chdir(), getcwd(), getpid(), getenv() — POSIX standard calls used throughout. Shell behavior matches standard Linux shell specifications.
PLATFORM
Linux / GCC
Compiled with GCC using -Wall -Wextra for zero warnings. Developed and tested on Linux WSL. Compatible with any POSIX-compliant system.
